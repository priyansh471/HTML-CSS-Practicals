# HTML & CSS Development Lab (BCS554)

# EXPERIMENT NO. 03

## 1. Experiment Title
Your First HTML Page

## 2. Aim
To write a first HTML page with a title, headings and a paragraph, and format some text.

## 3. Software / Tools Required
- HTML
- Visual Studio Code
- Web Browser

## 4. Theory
HTML (HyperText Markup Language) is used to structure webpages. A basic document contains `html`, `head`, `title` and `body`. Headings (`h1`-`h6`) and paragraphs (`p`) show text, and tags such as `strong` and `em` format it.

## 5. Algorithm / Procedure
1. Open Visual Studio Code.
2. Create `first.html` with the basic document structure, a title and a paragraph.
3. Create `headings.html` and add headings of different levels.
4. Create `text-format.html` and format text using bold, italic and other tags.
5. Save the files and open each in a web browser.

## 6. Program / Queries / Commands
| Task | File |
|------|------|
| Task 1 | `first.html` |
| Task 2 | `headings.html` |
| Task 3 | `text-format.html` |

Refer to the files above for the complete source code.

## 7. Input
Webpage content written in the HTML and CSS files.

## 8. Output
Webpages showing a title, headings, a paragraph and formatted text.

Output screenshots: `images/task0.png`, `images/task1.png`, `images/task2.png`

## 9. Result
Successfully created a basic HTML page with headings, a paragraph and formatted text.
